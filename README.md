# java-calculator-precourse
우아한테크코스 프리코스 1주차 과제: 문자열 덧셈 계산기
___

## 📝 구현 기능 목록

1. **입력**
    - [x]  계산기 시작 안내 문구 출력 (출력 형식: "덧셈할 문자열을 입력해 주세요.")
    - [x]  사용자로부터 연산할 문자열 입력받기

2. **처리**
    - [x]  구분자 기준으로 문자열 분리
        - [x] 기본 구분자(쉼표, 콜론) 처리
        - [x] 커스텀 구분자 처리 (한 글자 이상)
            - (예외 처리) 커스텀 구분자 유효성 검사: `IllegalArgumentException`
                - 구분자가 비어 있는 경우
                - 구분자에 숫자가 포함된 경우
    - [x]  분리된 문자열 배열을 숫자 배열로 변환
        - (예외 처리) 양수 변환 유효성 검사: `IllegalArgumentException`
            - 빈 문자열이 포함된 경우
            - 숫자로 변환할 수 없는 값이 포함된 경우
            - 0 또는 음수가 포함된 경우
    - [x]  숫자 총합 계산

3. **출력**
    - [x]  연산 결과 출력 (출력 형식: "결과 : 6")

---

## 🗂️ 클래스 구조 (MVC 패턴 기반)

### Controller
- CalculatorController: 전체 프로그램의 **흐름 제어** (입력 → 계산 → 출력)

### View
- InputView: 사용자 **입력** 처리
- OutputView: 덧셈 결과 **출력**

### Model
- **Service**
    - CalculatorService: 문자열 덧셈을 위한 핵심 **비즈니스 흐름 조율**
- **Domain**
    - StringParser: **유효한 구분자** 기준으로 **문자열 분리**
    - Numbers: **유효한 숫자** 목록으로 **변환**, 덧셈 **연산**
    - ErrorMessage: **예외** 메시지 관리
