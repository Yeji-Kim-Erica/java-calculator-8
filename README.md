# java-calculator-precourse
우아한테크코스 프리코스 1주차 과제: 문자열 덧셈 계산기
___
## 📝 구현 기능 목록

1. **입력**
    - [x]  계산기 시작 안내 문구 출력 (출력 형식: "덧셈할 문자열을 입력해 주세요.")
    - [x]  사용자로부터 연산할 문자열 입력받기

2. **처리**
    - [ ]  커스텀 구분자 처리
        - 커스텀 구분자 존재 여부 확인 및 추출
        - 커스텀 구분자 유효성 검사
    - [ ]  구분자 기준으로 문자열 분리
    - [ ]  분리된 각 문자열을 숫자로 변환
        - (예외 처리) 숫자로 변환할 수 없는 값이 포함된 경우 `IllegalArgumentException` 발생
        - (고민) 문자열 유효성 검사 및 예외 처리 시점
    - [ ]  모든 숫자의 합 계산
        - (고민) 합산 결과가 `int` 범위를 초과하는 경우 고려

3. **출력**
    - [ ]  연산 결과 출력 (출력 형식: "결과 : 6")
